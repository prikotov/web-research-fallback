# Web Research Fallback

Навык: проверить недоступный источник, а не сдаться после первой ошибки.
Скрипты сами проходят цепочку маршрутов и возвращают JSON-отчёт; агент читает
отчёт, фиксирует маршрут и дату в карточке источника и решает, что делать
дальше. Установка, требования и устройство клиента — в README.md.

## Когда использовать

Сайт не отвечает при исследовании: connect/read timeout, HTTP 000/403/502/429,
JS-challenge («Just a moment», «Client Challenge»). Не делай вывод «источник
недоступен» после первой попытки — пройди цепочку (скрипт делает её сам).
Доступность конкретных хостов из конкретной сети (проверено, с датами) —
`references/routes.md`; на другой сети картина может отличаться.

## Скрипты

Пути ниже — от корня каталога скилла.

### fetch.php — `scripts/fetch.php`

Достаёт тело недоступного URL, сам проходя цепочку маршрутов
(direct → браузерный UA и смена схемы при HTTP-отказе → прокси → RSS/Atom-экспорт
сайта → Wayback; при сетевой ошибке — сразу прокси; при TLS-отказе — бандл российских CA). Тело сохраняет в файл,
в stdout печатает JSON-отчёт о маршрутах и попытках.

#### Запуск

```bash
php scripts/fetch.php URL [опции]
```

#### Опции

| Опция | Описание | Значения | По умолчанию |
|-------|----------|----------|--------------|
| `URL` | Позиционный, обязательный: что проверяем | адрес страницы | — |
| `--out` | Куда сохранить тело | путь к файлу | `/tmp/wrf_<hash>.html` |
| `--proxy` | Прокси явно, поверх env и конфига | URL прокси | из env/конфига |
| `--timeout` | Секунд на попытку | число | 20 (вариации URL — 12) |
| `--no-wayback` | Не ходить в Wayback | флаг | выключено |
| `--ca` | Свой CA-бандл для обычных маршрутов (эмуляция машины без российских CA) | путь к PEM | системный trust store |
| `--feed` | Явная RSS/Atom-лента для шага feed (сайт вне карты FEEDS) | URL ленты | из карты FEEDS по хосту |

#### Примеры

```bash
# Проверить статью и сохранить тело для разбора
php scripts/fetch.php https://www.finam.ru/ --out /tmp/finam.html

# Медленный сайт: больше времени на попытку
php scripts/fetch.php https://example.com/ --timeout 40

# Явный прокси поверх конфига
php scripts/fetch.php https://example.com/ --proxy http://user:pass@host:port

# Только direct+прокси, без архива
php scripts/fetch.php https://example.com/ --no-wayback

# Тело в дефолтный /tmp-файл, отчёт читает агент
php scripts/fetch.php https://www.youtube.com/
```

#### Результат

- Тело страницы: файл из `--out` (или `/tmp/wrf_<hash>.html`) — разбирать его.
- stdout — JSON-отчёт:

| Поле | Описание |
|------|----------|
| `ok` | Получено ли тело (200 без JS-challenge) |
| `route` | Каким маршрутом взято: direct / direct-browser / direct-ruca / proxy / feed / wayback и их вариации |
| `status`, `bytes` | HTTP-статус и размер тела |
| `out` | Путь к сохранённому телу |
| `final_url` | Итоговый адрес после редиректов (для цитирования) |
| `proxy_available` | Был ли прокси в рантайме |
| `ru_ca_available` | Есть ли бандл российских CA в скилле |
| `attempts[]` | Каждая попытка: route, status, note (`challenge`, `curl errno N`, `no snapshot`) |

- Код выхода: 0 — тело получено, 1 — все маршруты мимо.
- `route=feed`: тело — XML item ленты (заголовок, ссылка, дата, текст статьи),
  `final_url` — адрес ленты; статью цитировать по `link` item, не по ленте.
- `ok=false` не значит «источника нет»: смотри `attempts` (где сломалось) и
  пробуй другие маршруты/архивы. Цепочку маршрутов скрипт проходит сам;
  порядок и обоснования — в README.
- Предупреждения (например, пополнение .gitignore) — в stderr, не в отчёте.

### search.php — `scripts/search.php`

Ищет URL источников по теме, когда адрес неизвестен или нужно набрать
материалов. Движки: Bing (рынок ru-RU) и lite.duckduckgo.com (POST `q=`);
цепочка auto: bing → ddg, каждый движок direct → прокси.
google/yandex/mail.ru не используем: JS-оболочка или captcha (проверено 2026-11-25).

#### Запуск

```bash
php scripts/search.php "запрос" [опции]
```

#### Опции

| Опция | Описание | Значения | По умолчанию |
|-------|----------|----------|--------------|
| `"запрос"` | Позиционный, обязательный: формулировка как для поисковика | строка | — |
| `--limit` | Сколько результатов вернуть | число (например: 5, 10, 20) | 10 |
| `--engine` | Движок поиска | `auto`, `bing`, `ddg` | `auto` (bing → ddg) |
| `--proxy` | Прокси явно, поверх env и конфига | URL прокси | из env/конфига |

#### Примеры

```bash
# Найти источники по теме
php scripts/search.php "moex retail investors share 2021"

# Узкая выдача для быстрого просмотра
php scripts/search.php "обзор рисков финансовых рынков" --limit 5

# Больше кандидатов для каталогизации
php scripts/search.php "объем торгов акциями вторичный рынок" --limit 20

# Только ddg (например, если Bing отдал captcha)
php scripts/search.php "обзор рисков финансовых рынков" --engine ddg
```

#### Результат

stdout — JSON:

| Поле | Описание |
|------|----------|
| `results[]` | Список: `title` (заголовок), `url` (адрес), `snippet` (сниппет выдачи) |
| `engine` | Каким движком найдено: bing или ddg |
| `route` | bing / ddg / bing-proxy / ddg-proxy |
| `status`, `note` | HTTP-статус и пометка ошибки |

Сниппет — не проверенный факт: каждый перспективный URL открывай через
`fetch.php` (правила — «Фиксация результата»).

### Прокси (общий для обоих скриптов)

Порядок разрешения: `--proxy` → env `WEB_RESEARCH_PROXY` → собственный конфиг
скилла `.wrf_config.json` (путь можно задать через `WRF_CONFIG`); настройка —
в README. Значение прокси не выводится ни в stdout, ни в отчёты, ни в файлы;
в отчётах только имена маршрутов и `proxy_available`.

## Безопасность

- Секреты (прокси) — только собственный конфиг скилла или рантайм-env;
  не в код, коммиты, логи, отчёты, заметки. Env-файлы проектов ради прокси
  не читать и не писать.
- 🔴 Никогда `curl -v` с прокси: debug печатает URL прокси с учётными данными.
- Не отключать проверку сертификатов (`-k` / VERIFYPEER=false): TLS-отказ
  лечит шаг `direct-ruca` с явным CAINFO, а не слепое доверие.
- Не обходить платные подписки и авторизацию; Wayback — публичный архив.
- Уважать rate limit: паузы, не долбить 429.
- Временные файлы — в `/tmp`, не мусорить в проекте.

## Фиксация результата

- **Зафиксируй маршрут и дату** в карточке источника/отчёте проекта: что
  пробовал, итог «проверено (маршрут, снапшот)» или «не проверено».
- Отсутствие доступа ≠ отсутствие содержимого; содержимое за JS-challenge
  не додумывать.
- Сниппет поисковика — не проверенный факт: факт только из тела, взятого
  через `fetch.php`.
