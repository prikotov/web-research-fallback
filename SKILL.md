# Web Research Fallback (доступ к недоступным источникам)

## Когда использовать

При исследовании (маркетинг, конкуренты, источники) сайт не отвечает: connect/read timeout, HTTP 000/403/502/429, JS-challenge («Just a moment», «Client Challenge»). Не делай вывод «источник недоступен» после первой попытки — пройди цепочку ниже.

## Цепочка доступа (по порядку)

1. **Диагностируй ошибку.** `curl -sS -o file -w "%{http_code} %{size_download}"` или python `requests` с перехватом исключения. Различай: connect timeout (сеть/блокировка), read timeout (сервер принял, но молчит), HTTP-код (403 — блокировка/гео, 429 — rate limit, 502 — прокси не достучался до origin).
   🔴 Никогда не используй `curl -v` с прокси: debug выводит URL прокси с учётными данными.
2. **Повтори напрямую с вариациями:** другой User-Agent (браузерный), `http` vs `https`, `www` vs без `www`, увеличенный timeout (до 45–60 с).
3. **Повтори через прокси.** Прокси бери в рантайме из `.env.dev.local` (ключ `YT_DLP_PROXY`), значение не выводи в stdout/логи/файлы:
   ```bash
   PROXY=$(grep '^YT_DLP_PROXY=' .env.dev.local | cut -d= -f2- | tr -d '"' | tr -d "'")
   curl -sL --proxy "$PROXY" -A "Mozilla/5.0" "<url>" -o out.html -w "%{http_code} %{size_download}\n"
   ```
   Пробуй и https, и http через прокси. Прокси меняет exit IP — помогает при гео-блокировках и 429 по IP.
4. **Сайт мёртв на обоих маршрутах → Wayback Machine:**
   - Наличие снапшота: `curl -s "http://archive.org/wayback/available?url=<URL>"` (API обычно доступен напрямую).
   - Список снапшотов: `curl -s "https://web.archive.org/cdx/search/cdx?url=<URL>&output=json&limit=5&filter=statuscode:200"`.
   - Загрузка снапшота: `https://web.archive.org/web/<timestamp>/<URL>`. При 429 (bot-блок) — повтори через прокси.
   - Пагинацию и `?singlepage=1` проверяй внутри снапшота.
5. **JS-challenge (Scribd и т.п.):** пробуй Wayback; если не вышло — статус «не проверено», содержимое не додумывать.
6. **Зафиксируй результат в карточке исследования:** что пробовал (direct/proxy/варианты/Wayback), дата, итоговый статус «проверено» (с указанием маршрута и снапшота) или «не проверено». Отсутствие доступа ≠ отсутствие содержимого; не выдавай сниппет поисковика за проверенный факт.

## Безопасность

- Секреты (прокси, токены) — только рантайм из env-файлов; не записывать в код, коммиты, логи, отчёты, артефакты.
- Не обходи платные подписки и авторизацию; Wayback — публичный архив, допустим.
- Уважай rate limit: паузы между запросами, не долби 429.

## Известные особенности сети владельца (проверено 2026-11-13)

- Прямой доступ из РФ ограничен: YouTube и часть сайтов — connect timeout; через прокси работают.
- `archive.org` API (metadata, wayback/available, CDX) доступен напрямую; `web.archive.org` снапшоты могут давать 429 — через прокси отдают 200.
- `api.github.com`, `suggestqueries.google.com`, `cbr.ru`, `eutils.ncbi.nlm.nih.gov` доступны напрямую.
- Пример цепочки: singjupost.com (direct timeout → proxy read timeout/502 → Wayback снапшот 2022-12-09 через прокси → содержимое проверено).
